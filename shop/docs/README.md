## ۴. دستورهای پرکاربرد

```bash
npm install                  # نصب وابستگی‌ها (package-lock.json را تغییر ندهید)
npx prisma generate          # تولید کلاینت Prisma
npm run prisma:deploy        # اعمال مایگریشن‌ها (در تولید فقط همین، هرگز migrate dev)
npm run db:seed              # نقش‌ها، دسترسی‌ها، اپراتورها، تنظیمات، حساب سوپر‌ادمین
npm run dev                  # اجرای محلی روی :3000
npm run typecheck            # tsc --noEmit
npm test                     # vitest (با دیتابیس واقعی، تست‌های یکپارچه هم اجرا می‌شوند)
npm run build                # بیلد پروداکشن
npm run smoke                # ۲۷ بررسی HTTP واقعی روی سرور در حال اجرا
npm run excel:template       # ساخت قالب‌های نمونه‌ی اکسل در samples/
```

اسموک تست روی دامنه‌ی واقعی (پس از هر دیپلوی):

```bash
BASE_URL=https://shop.example.ir ADMIN_PASSWORD='...' npm run smoke
```

## ۶. اصول حاکم بر این مستندات

- **هر ادعا با فایل یا دستور قابل بررسی است.** ارجاع به مسیر کد (`src/lib/...`) و اندپوینت (`GET /api/...`) در متن آمده تا بتوانید راستی‌آزمایی کنید.
- **فارسی و راست‌به‌چپ.** همه‌ی اسناد با اعداد فارسی و اصطلاحات فنی رایج نوشته شده‌اند.
- **بدون راز.** هیچ کلید، رمز یا توکنی در مستندات نیست؛ مقادیر واقعی فقط در `.env` سرور قرار می‌گیرند (از `../.env.example` بسازید).
- **در تولید:** هرگز `npm run db:reset` یا `prisma migrate dev` نزنید؛ فقط `npm run prisma:deploy`.
